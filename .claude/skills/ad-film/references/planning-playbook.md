# 광고 기획 플레이북 (ad-planner 형식)

## 1. 크리에이티브 브리프 (1장)
| 항목 | 쓰는 법 |
| --- | --- |
| 과제 | 이 광고가 바꿔야 할 행동 하나 (예: 링크를 누르게 한다) |
| 타깃 | 한 사람처럼 구체적으로: 나이대, 사는 곳, 그 순간의 상황 |
| 인사이트 | "~하지만 ~". 근거 없으면 (가설) |
| 단일 메시지 (SMP) | 소비자가 기억할 한 문장, 혜택 중심 |
| 믿을 이유 (RTB) | 팩트 시트 안의 사실만, 출처 표기 |
| 톤앤매너 | 형용사 3개 + 레퍼런스 성격(장면 복제 금지) |
| 필수 요소 | 광고 표기, 제품 실사 컷, 슬로건, 사운드 로고, CTA |
| 금지 사항 | 근거 없는 수치·비교·효능, 타 브랜드 표현 |

## 2. 빅 아이디어 평가표
| 기준 | 질문 |
| --- | --- |
| 전략 적합 | SMP를 가장 빠르게 느끼게 하나 |
| 독창성 | 같은 카테고리 광고에서 본 적 없나 |
| 기억성 | 한 장면·한 문장으로 떠오르나 |
| AI 제작 가능성 | 4–5초 컷, 동작 하나씩으로 만들 수 있나 |
| 법적 리스크 | 오인·과장·사칭 소지 (점수 높을수록 안전) |

## 3. 콘티 표 형식
| 컷 | TC | 샷/앵글/무빙 | 화면 | 자막 | NA | SFX/BGM | 전환 | 제작 |

- TC는 초 단위 소수 1자리. 15초 합계를 맞춘다.
- 제작 칸: `AI` / `AI+상품사진` / `사진합성` / `사진 필요`.
- 스케치 프롬프트는 영문, "advertising storyboard frame, black marker and grey copic sketch on white paper, no text, no logos" 로 시작.

## 4. 15초 기본 구조
훅 0–2 · 긴장 2–5 · 전환 5–8 · 증명 8–12 · 패키샷(슬로건+사운드 로고+CTA) 12–15
6초 범퍼 = 훅 1.5 + 증명 2 + 패키샷 2.5
