# 크리에이티브 브리프 — 진공 압축팩 15초

| 항목 | 내용 |
| --- | --- |
| 과제 | 환절기 이불 정리를 떠올린 순간 "프로필 링크 1번"을 누르게 한다 |
| 타깃 | 원룸·소형 아파트에 사는 20–30대 1인 가구. 9월 말, 여름 이불을 넣으려는데 옷장이 꽉 찬 순간 |
| 인사이트 (가설) | 이불은 1년에 두 번 꺼내지만, 옷장 자리는 1년 내내 차지한다. 그래서 환절기마다 옷장 문을 등으로 밀어 닫는다 |
| 단일 메시지 (SMP) | 옷장에 숨 쉴 공간을 돌려준다 |
| 믿을 이유 (RTB) | 진공 압축으로 이불 부피를 줄인다 · 다시 쓸 수 있다 (출처: 쿠팡 상품명 "진공 압축 이불압축보관 공간절약 재사용가능 압축팩", 웹 검색 결과 제목, 2026-09-26 확인. 상세 사양은 미확인) |
| 톤앤매너 | 위트 있는 · 시네마틱한 · 시원한. 과장된 긴장 뒤에 한 번에 풀리는 해방감 |
| 필수 요소 | 광고 표기(상단 고정 + 캡션 첫 줄), 실제 상품 사진 컷, 슬로건, 사운드 로고, "프로필 링크 1번" |
| 금지 사항 | 부피 %·몇 배·몇 분 같은 수치, 타 브랜드 비교, 후기·순위, 전후 비교 연출, 브랜드 사칭 |
